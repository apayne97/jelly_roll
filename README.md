This repo is a little playground for trying to understand autoencoders and diffusion models inspired by the simple example of the jelly roll spiral.
Heavily based on https://www.youtube.com/watch?v=iv-5mZ_9CPY&list=PLi08UU332zJ5zkj0rCH5IFFVVThtMAqRF&index=9

The package can be installed by cloning the repo and running:
```
conda env create -f environment.yaml
pip install -e .
```
